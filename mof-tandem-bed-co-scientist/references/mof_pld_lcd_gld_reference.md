# MOF PLD/LCD/GLD Reference

This file stores user-provided MOF descriptor rows for geometric screening. Values are in Angstrom unless otherwise noted.

Use this as a project-local descriptor reference. The database source, calculation method, probe radius, framework treatment, and disorder/solvent handling should be recorded before publication-grade screening.

## Schema

| field | meaning |
|---|---|
| material | material identifier |
| PLD_A | pore limiting diameter |
| LCD_A | largest cavity diameter |
| GLD_A | global/transport/path limiting descriptor as supplied by the database |
| density | framework density |
| ASA_m2_g | accessible surface area |
| AV_cm3_g | accessible volume |
| AV_fraction | accessible volume fraction |
| source_or_batch | user-provided descriptor batch |
